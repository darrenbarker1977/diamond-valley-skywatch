Make it large like the Duolingo widget

The Duolingo item is a widget. A normal shortcut has a fixed launcher icon size; a bigger PNG does not enlarge only that shortcut.

  1. Download the circular PNG above on the Pixel.
  2. Use an image/shortcut widget provider, such as KWGT, with Lawnchair. Lawnchair displays the widget; it does not itself turn a normal shortcut into a large photo widget.
  3. Add a roughly 2 × 2 widget, select this image, and set its tap action to open https://darrenbarker1977.github.io/diamond-valley-skywatch/.
  4. Long-press and resize the widget until its diameter is close to the Duolingo widget's width. This avoids the Chrome shortcut badge because the widget draws your chosen image.

Chrome on your Pixel 8

  1. Open the permanent site in Chrome, then use its three-dot menu → Add to Home screen. Choose Install app or Install if offered, rather than a basic shortcut. A basic Chrome shortcut may carry a Chrome badge.
  2. The installed app may be listed as After Dark, its short name. Search that name in the app drawer. If it is listed in Android Settings → Apps but not Lawnchair, restarting Lawnchair can refresh the drawer. If it is not in Settings → Apps, app installation has not completed.
  3. Test the new shortcut, then remove the old duplicate if you want. Other Chrome shortcuts and the Chrome app icon are unaffected.

Lawnchair

  1. Download the PNG above on the Pixel.
  2. Long-press this site's shortcut and open its edit/customize option, if available.
  3. Tap the icon and choose the downloaded image if your Lawnchair version offers a gallery/file picker. Menu names and image-picker support vary by version.

If your launcher only offers icon packs, use Chrome's new Add to Home screen icon instead. The web-app manifest is scoped to this site, not all of Chrome.
